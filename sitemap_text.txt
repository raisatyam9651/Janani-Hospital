1. Project Overview
This document provides the complete sitemap, page-by-page specifications, and technical integration details for
the Janani Hospitals WordPress website. The site includes a fully automated appointment booking system
powered by the WP Amelia plugin, with automated email confirmations sent to both patients and doctors upon
booking completion.

7. Developer Notes & Delivery Checklist

7.1 Important Requirements
    •     All doctor profiles must be added as 'Employees' in WP Amelia before the site goes live.
    •     SMTP must be tested and confirmed working before publishing the booking page.
    •     Email notification templates in Amelia must include all booking variables: patient name, doctor, date, time,
          location.
    •     Each department must be created as a 'Service Category' in Amelia for filtering to work on /doctors page.
    •     The /book-appointment page must be tested on mobile — majority of hospital bookings come from mobile
          users.
    •     Google Maps API key must be configured for the Contact page map embed.
    •     SSL certificate must be active (HTTPS) for form security and patient data protection.



7.2 Pre-Launch Checklist
    •     All 15 pages created and published
    •     WP Amelia configured: Services, Employees, Locations, Working Hours
    •     SMTP email delivery tested for both patient and doctor notifications
    •     Test booking completed end-to-end — patient email received, doctor email received
    •     Mobile responsiveness checked on all pages
    •     Page speed tested (Google PageSpeed Insights — target score 80+)
    •     SEO plugin configured with meta titles and descriptions for all pages
    •     Google Analytics / Search Console connected
    •     Contact forms tested
    •     SSL active — all pages loading on HTTPS
    •     404 page customised
